## Getting Started

Clone the repository:

```bash
git clone git@github.com:masudranahimel/masudranahimel.git
```

Enter the project directory:

```bash
cd masudranahimel
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open `http://localhost:3000` in your browser.

## Production Build

```bash
npm run build
```
